# feature_markdown — MD 문서 screen (MD area). Plan: [docs/plans/m5-7/08-markdown.md](../../docs/plans/m5-7/08-markdown.md)

The rendered view (보기) and the source editor (편집) of an MD 문서 — a note whose format is markdown, its text kept byte for byte in note_core (`MarkdownRepository`). Rendering uses dart-lang's pure-Dart `markdown` parser (GFM) and the package's own widgets; math goes through ink_engine's `MathPreview`; colours come only from ui_kit's `StyleTokens` / `ColorScheme`. Plugin free (R16): files, sharing and opening links are the app's slots in `lib/slots.dart`. Two entry points: `feature_markdown.dart` (`MarkdownScreen`, `MarkdownKeys` — imported `deferred` by the app on the web, because the parser is about 59 KB gzip) and `slots.dart` (slot providers only, no parser — imported eagerly). State: foundation stub (public API fixed in 08-markdown 12.2); Track B builds the screen inside `lib/src/`.
