## 모든 안내서에 공통인 것

- 맨 위에 걸리는 시간, 준비물, 끝나면 Claude에게 알려 줄 것이 있어요.
- 단계마다 어느 화면에서 무엇을 누르는지 적었어요. 메뉴를 못 찾으면 콘솔 위쪽 검색창에 메뉴 이름을 입력해 보세요.
- 콘솔(Firebase · Google Cloud · GitHub · Apple) 화면의 메뉴 이름은 안내서를 쓸 때의 기억을 바탕으로 적었어요. 화면이 안내서와 다르면 스크린샷을 보내 주세요. 안내서를 고쳐 드릴게요.
- 마지막에 '확인 방법'과 '문제 해결'이 있어요.
- 웹 버전은 테스트용이에요. 중요한 노트는 쓰지 마세요.
