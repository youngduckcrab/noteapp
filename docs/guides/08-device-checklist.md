# 08. 실기기 체크리스트 (2차 — 편집·녹음·인식)

2차 라운드(편집 도구·녹음·인식)를 실제 기기에서 확인하는 목록이에요. **A**는 안드로이드 태블릿, **B**는 iPad 웹(Safari·홈 화면 앱), **C**는 TestFlight 뒤(지금은 하지 않아요)예요. 굵은 번호 뒤의 문장은 계획의 체크리스트(계약 7.8)와 글자 그대로 같아요. 문장이 짧아서 알기 어려우면 바로 아래 '알려 줄 것'과 04·05의 '하는 법'을 봐요.

- **소요 시간**: A 약 1시간 30분, B 약 2시간 30분(B-8 녹음 30분, B-13 복합 항목 포함), C는 나중에
- **끝나면 Claude에게 알려줄 것**: 아래 '확인 방법'의 결과 보고 양식으로, 항목마다 통과 / 실패 / 못 함과 메모(사진이 있으면 함께)

## 준비물

- A: 안드로이드 태블릿(A-2는 S펜이 있을 때), [05](05-android-apk.md)·[07](07-android-signing.md)로 설치한 고정 키 APK, Wi-Fi(A-4 모델 받기)
- B: iPad와 Apple Pencil, [04](04-ipad-web-test.md)로 연 홈 화면 앱, 사진 몇 장(HEIC 사진 포함 — iPad 카메라로 찍은 사진은 보통 HEIC예요), 200쪽쯤 되는 PDF(B-13)
- C: TestFlight로 설치한 앱(Apple 유료 계정 가입 뒤 — [06](06-ios-testflight.md))

## 먼저 알아 둘 것

- 항목 문장의 '개발자 표시'는 **설정 → 개발자 표시**에서 켜면 화면에 겹쳐 보이는 줄이에요. '개발자 메뉴'는 설정 화면 아래쪽의 **개발자 표시**·**기능 켜고 끄기**·**이전 판 DB 사본** 섹션이에요.
- B의 머리말과 B-1은 'live 채널'이라고 적혀 있어요. `main`이 생기기 전에는 Claude가 알려 주는 개발 브랜치 미리보기 주소가 그 자리예요([04](04-ipad-web-test.md)의 1단계).
- B-1은 실제 노트가 있는 홈 화면 앱에서, 나머지 B는 Claude가 알려 주는 미리보기 주소(빈 데이터)에서 해요. 미리보기 주소에는 중요한 노트를 쓰지 마세요.
- 한 번에 다 하지 않아도 돼요. 한 항목을 끝낼 때마다 결과를 보내 줘도 돼요.

## A. 안드로이드 APK

> 안드로이드 APK (안드로이드 태블릿이 있을 때 — U2. 없으면 '코드만, 확인은 이후'로 표시)

안드로이드 태블릿이 없으면 A는 건너뛰고 'A 없음'이라고만 알려 주세요.

- [ ] **A-1** 고정 키 2차 APK에서 노트·이미지·녹음 작성 → 다음 판 고정 키 APK를 덮어 설치 → 모두 남아 있음(파일 DB·파일 에셋). 처음 한 번은 기존 앱(1차 debug 서명 APK — 러너마다 키가 다르고 노트를 저장하지 못했다)을 지우고 설치한다. '설치되지 않음'이 뜨면 앱을 지우지 말고 알린다
  - 알려 줄 것: 덮어 설치가 됐는지, 노트·이미지·녹음이 모두 남았는지. 설치되지 않으면 그 화면 사진(앱은 지우지 말고 기다려 주세요).
- [ ] **A-2** S펜: 닿은 채 측면 버튼 누르고 쓰기 → 지우기, 버튼 떼면 펜. Air command 켬/끔 각각
  - 알려 줄 것: Air command 켬·끔 각각 통과 / 실패, 지우개로 바뀌지 않은 때가 있으면 그때 한 동작.
- [ ] **A-3** 녹음 → 홈으로 나감·화면 끔 5분 → 돌아와 정지 → 길이·재생 정상, 알림 표시
  - 알려 줄 것: 앱에 보이는 녹음 길이와 실제로 녹음한 시간, 녹음 중 알림이 보였는지.
- [ ] **A-4** ML Kit `ko` 모델 받기(크기 기록), `en` 모델도 받기(크기 기록), 한국어 문장·혼용 문장 30줄 문자 오류율(`ko` 단독 vs `ko`+`en`), 줄당 인식 시간
  - 알려 줄 것: 두 모델의 크기(받기 화면에 보이는 값, 안 보이면 '모름'), 30줄에서 틀린 글자 수(`ko`만 / `ko`+`en`), 한 줄이 인식되기까지 대략 몇 초인지.
- [ ] **A-5** 녹음 시계 오차 10회(파일 길이 − 시계) → 150 ms 넘게 일정하면 보정 필드 검토
  - 알려 줄 것: 1분쯤씩 10번 녹음한 뒤 개발자 표시 `녹음`(`media`) 섹션의 줄을 사진으로.
- [ ] **A-6** 가로·세로·분할 화면에서 에디터·녹음 패널
  - 알려 줄 것: 화면 모양마다 통과 / 실패, 잘리거나 겹친 곳 사진.

## B. iPad 웹

> iPad 웹(Safari, 홈 화면 앱) — Firebase Hosting이 생긴 뒤(3.7, U24). 통합 미리보기 채널에서 확인하고, B-1만 실제 노트가 있는 live 채널

- [ ] **B-1** 1차로 쓴 실제 노트가 있는 출처(live 채널 홈 화면 앱 — U25)에서: 배포 전 백업 내보내기 → 그 출처에 2차 배포 → 첫 실행 → 노트가 그대로 열림(DB v2 이주) → 개발자 메뉴에 v1 사본 있음. 실제 노트가 없으면 1차 빌드로 노트 몇 개를 만든 뒤 같은 절차
  - 하는 법: [04](04-ipad-web-test.md)의 '10단계 — 2차 판으로 옮기기'. 알려 줄 것: 네 단계 각각의 결과, **이전 판 DB 사본** 섹션 사진.
- [ ] **B-2** 텍스트 상자 한글 입력: 조합 중 글자·자동 완성·받침 이동·줄바꿈, 확대 상태에서 입력
  - 알려 줄 것: 이상하게 들어간 글자와 그때 한 동작(확대 배율도).
- [ ] **B-3** 사진 보관함·카메라로 이미지 삽입(HEIC 사진 포함), 이미지 페이지. 삽입 메뉴·페이지 추가 시트에서 사진 보관함·카메라·붙여넣기가 한 번 눌러 바로 열림(사용자 동작 활성화 — 7.2.10)
  - 알려 줄 것: HEIC 사진이 들어갔는지, 각 버튼이 한 번에 열렸는지(두 번 눌러야 열리면 실패).
- [ ] **B-4** 도형 도구 7종, 자동 도형 보정(멈춤 500 ms)의 오인식 체감, 꼭짓점 편집
  - 알려 줄 것: 도형마다 통과 / 실패, 보정이 원하지 않게 일어난 횟수(대략 10번 중 몇 번).
- [ ] **B-5** 올가미 회전 15° 맞춤·색 변경·잘라내기·붙여넣기(획 + 객체)
  - 알려 줄 것: 동작마다 통과 / 실패.
- [ ] **B-6** 붓펜·캘리그래피·점선 필기감, 레이저 사라짐, 테이프 가림·탭 드러냄
  - 알려 줄 것: 펜마다 느낌(괜찮음 / 끊김 / 늦음), 레이저·테이프 통과 / 실패.
- [ ] **B-7** 제스처 동작 바꾸기(두 손가락 탭 → 다시 실행 등)
  - 알려 줄 것: 바꾼 제스처와 결과.
- [ ] **B-8** 녹음 30분(앞에 둔 채) → 재생 강조·필기 탭 재생·배속, `isEncoderSupported`·MIME(개발자 표시). 패널 열기 직후 재생 바 길이 표시, 녹음 정지 직후 필기가 흐려지지 않음
  - 알려 줄 것: 동작마다 통과 / 실패, 개발자 표시 `녹음` 섹션 사진(MIME 줄이 보이게).
- [ ] **B-9** 녹음 중 앱 전환·화면 잠금 → 자동 일시정지·안내, Screen Wake Lock. 앱 전환 → 돌아와 이어서 녹음 → 정지 → 한 파일로 재생
  - 알려 줄 것: 안내 문구 사진, 녹음 중 화면이 저절로 꺼졌는지, 이어서 녹음한 것이 한 파일로 재생됐는지.
- [ ] **B-10** 검색: 텍스트 상자·PDF 텍스트·수식으로 찾기 → 결과 누르면 그 페이지·위치로
  - 알려 줄 것: 세 종류마다 찾았는지, 결과를 누르면 그 위치로 갔는지.
- [ ] **B-11** 수식: LaTeX 입력 → 렌더, 크기·색, LaTeX 복사(선택 메뉴 '텍스트 복사' → 메모에 붙여넣기 됨), PDF 내보내기(루트·연립방정식 기호 포함)
  - 알려 줄 것: 동작마다 통과 / 실패, 내보낸 PDF 파일(가능하면).
- [ ] **B-12** Pencil 호버가 `kind: stylus` 호버로 오는가(개발자 표시)
  - 알려 줄 것: 펜슬을 화면에 대지 않고 띄운 채 움직일 때 개발자 표시의 입력 줄 사진(펜슬 종류도).
- [ ] **B-13** 복합: PDF 200쪽 + 이미지 20개 + 녹음 30분 노트에서 스크롤·필기·재생·내보내기 → 탭 재로드 없음, 개발자 표시 캐시 합계 ≤ 300 MB, 내보낸 PDF를 다른 앱에서 열어 텍스트 상자 글자가 검색됨. 1차 7.7 V7 복합 항목(PDF 500쪽)도 다시. PDF 500쪽 색인이 끝난 뒤 앱 다시 열기 시간·메모리 기록
  - 하는 법: 아래 'B-13 순서'. 알려 줄 것: 단계마다 통과 / 실패, 캐시 합계 값, 다시 열기 시간.
- [ ] **B-14** 녹음 중 Safari 탭 닫기(또는 새로 고침) → 다시 열면 '복구된 녹음'이 목록에 있고 길이가 닫기 직전까지(오차 ≤ 1초), 녹음 중 쓴 획의 탭 재생 동작
  - 알려 줄 것: 닫기 직전 녹음 시간(시계로 잰 값)과 '복구된 녹음'의 길이.
- [ ] **B-15** 텍스트 상자(키보드 없이): 두 번 탭 낱말 선택·선택 손잡이·붙여넣기 메뉴, 편집 중 두 손가락 스크롤·핀치에도 편집이 이어짐, 편집이 끝날 때 글자가 튀지 않음
  - 하는 법: [04](04-ipad-web-test.md)의 'B-15 하는 법'. 알려 줄 것: 동작마다 통과 / 실패.
- [ ] **B-16** 녹음 패널을 연 채(재생 안 함) 녹음된 글씨 위에 마침표 → 점이 남음, 손가락 탭 → 그 시점부터 재생, 재생 중 펜 점 → 그 시점으로 이동
  - 하는 법: [04](04-ipad-web-test.md)의 'B-16 하는 법'. 알려 줄 것: 세 동작 각각 통과 / 실패.

### B-13 순서

1. 미리보기 주소의 새 노트에 200쪽쯤 되는 PDF를 가져와요.
2. 이미지 20개를 여러 페이지에 나눠 넣어요.
3. 녹음 패널을 열고 30분 녹음하면서 가끔 필기해요.
4. 노트를 닫았다 다시 열고, 처음부터 끝까지 스크롤하면서 중간 페이지에 필기해요.
5. 녹음을 재생하고, 필기를 눌러 그 시점부터 재생해 봐요.
6. 노트를 PDF로 내보내요.
7. 그동안 화면이 하얗게 되며 처음부터 다시 열린 적(탭 재로드)이 있었는지 적어요. 개발자 표시의 캐시 합계 값을 사진으로 남겨요.
8. 내보낸 PDF를 파일 앱 등 다른 앱에서 열어 텍스트 상자에 쓴 낱말을 검색해요.
9. 같은 순서를 500쪽쯤 되는 PDF로 한 번 더 해요(1차 복합 항목). 검색 색인이 끝난 뒤(개발자 표시의 색인 줄이 '대기 0'), 앱을 완전히 닫았다 열어 시작까지 걸린 시간과 **설정 → 앱 정보**의 단계별 시간을 사진으로 남겨요.

## C. TestFlight 뒤

> TestFlight 뒤(Apple 유료 계정 가입 후) — 2차 완료 조건이 아니다

지금은 하지 않아요. Apple 유료 계정에 가입하고 [06](06-ios-testflight.md)으로 앱을 설치한 뒤에 해요.

- [ ] **C-1** Pencil 더블탭·스퀴즈(시스템 설정 따르기·앱 설정), 배럴 롤 캘리그래피, 호버 높이
  - 알려 줄 것: 동작마다 통과 / 실패. iPadOS의 Apple Pencil 설정을 바꾼 뒤에는 **앱을 완전히 닫았다 열어요**(앱은 시작할 때 한 번만 펜슬 설정을 읽어요). **설정 → 앱 정보**의 'Apple Pencil' 줄 사진도 함께.
- [ ] **C-2** 백그라운드 녹음(앱 전환·잠금), 녹음 → 재생 전환 때 세션·스피커, 다른 앱 음악 재개(조사 02 D5)
  - 알려 줄 것: 동작마다 통과 / 실패, 소리가 이어폰·스피커 중 어디로 나왔는지.
- [ ] **C-3** ML Kit iOS 인식(A-4와 같은 목록), 모델 받기가 셀룰러를 막는지
  - 알려 줄 것: A-4와 같은 값, 셀룰러에서 모델 받기가 시작됐는지.
- [ ] **C-4** 네이티브 필기 지연(PLAN 5.4 20 ms) — 1차부터 미뤄진 판정
  - 알려 줄 것: 웹 홈 화면 앱과 비교한 느낌(더 빠름 / 같음 / 더 느림).

## 확인 방법

항목마다 아래 양식을 한 번씩 채워 보내 주세요. 여러 항목을 한 메시지에 이어 붙여도 돼요.

```text
기기: (예: iPad Pro 13 M4 · iPadOS 18.1 / Galaxy Tab S9 · Android 15)
판: (설정 → 앱 정보 → 빌드 줄, 예: 0.2.0 (#57 · a1b2c3d · preview))
항목: (예: B-3)
결과: 통과 / 실패 / 못 함
메모: (본 것, 기록한 값, 사진이 있으면 '사진 첨부')
```

- 같은 판에서 한 결과면 기기·판 줄은 처음 한 번만 적어도 돼요.
- '못 함'은 기기나 준비물이 없어서 못 한 항목이에요. 이유를 메모에 적어 주세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 항목 문장이 무슨 뜻인지 모르겠어요 | 번호와 함께 물어봐 주세요. 하는 법을 풀어서 알려 드릴게요. |
| 개발자 표시가 안 보여요 | **설정 → 개발자 표시**에서 켜요. 그래도 없으면 빌드 줄과 함께 알려 주세요. |
| 녹음 버튼이나 인식 메뉴가 없어요 | **설정 → 기능 켜고 끄기**에서 꺼져 있는지 봐요. '이 빌드에서 꺼져 있어요'이면 Claude에게 알려 주세요. |
