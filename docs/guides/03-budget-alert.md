# 03. 예산 알림 설정하기

지금 쓰는 Spark(무료) 요금제에는 결제 계정이 없어서 예산 알림을 걸 수 없어요. **M4(동기화)에서 Storage·Functions 때문에 Blaze 요금제로 바꿀 때 바로** 이 안내서를 따라 해요. Hosting 릴리스 보관 개수(4단계)는 지금 해 둬도 좋아요.

- **소요 시간**: 약 10분
- **끝나면 Claude에게 알려줄 것**: 예산 금액과 알림 비율, Hosting 릴리스 보관 개수를 10개로 바꿨는지

## 준비물

- Blaze 요금제로 바꾼 Firebase 프로젝트(결제 계정이 연결돼 있어야 해요)
- 결제 계정 관리 권한(결제 계정을 직접 만들었으면 있어요)
- 컴퓨터 브라우저

## 알아 둘 것

- 서버 함수(Functions) 배포는 실연결 미니 라운드에서 해요. 2차 라운드에서는 Hosting만 써서 Blaze로 바꿀 일이 없어요.
- **예산 알림은 요금을 멈추지 않아요.** 정한 금액에 가까워지면 이메일만 보내요. 알림을 받으면 Claude에게 알려 주세요.
- 무료 사용량(Hosting 저장 10GB · 전송 하루 360MB)은 이 안내서를 쓸 때의 기억이에요(미확인). Firebase 콘솔 **사용량 및 결제**에서 실제 값을 확인해요.

## 따라 하기

### 1단계 — 결제 화면 열기

1. <https://console.cloud.google.com> 을 열고 위쪽 프로젝트 선택 상자에서 01의 프로젝트를 골라요.
2. 왼쪽 메뉴 **결제**를 눌러요. 안 보이면 콘솔 위 검색창에 '결제'를 입력해요.
3. 결제 계정을 고르라는 화면이 나오면 이 프로젝트에 연결된 결제 계정을 골라요.

### 2단계 — 예산 만들기

1. 왼쪽 **예산 및 알림** → 위쪽 **예산 만들기**를 눌러요.
2. 이름: `noteapp`. 범위(프로젝트): 01의 프로젝트만 골라요. **다음**.
3. 금액: **지정 금액**을 고르고 `1000`(원)을 입력해요. **다음**.

### 3단계 — 알림 비율 정하기

1. 알림 기준을 **50%**, **90%**, **100%** 세 줄로 맞춰요(기본값이 다르면 줄을 고치거나 추가해요).
2. **결제 관리자 및 사용자에게 이메일 알림 보내기**를 켜요.
3. **완료**를 눌러요.

### 4단계 — Hosting 릴리스 보관 개수

배포할 때마다 이전 버전이 쌓여 저장 공간을 차지해요. 최근 10개만 남겨요.

1. Firebase 콘솔(<https://console.firebase.google.com>) → 프로젝트 → **Hosting**을 눌러요.
2. **릴리스 기록** 표 오른쪽의 점 세 개(⋮) 메뉴 → **릴리스 보관 설정**을 눌러요.
3. 보관 개수를 `10`으로 바꾸고 저장해요.

## 확인 방법

- Google Cloud 콘솔 **결제 → 예산 및 알림** 목록에 `noteapp` 예산이 보이고, 금액 1,000원·알림 50·90·100%예요.
- Firebase 콘솔 **Hosting → 릴리스 보관 설정**을 다시 열면 10개로 되어 있어요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| **예산 및 알림** 메뉴가 안 보여요 | 결제 계정 관리 권한이 필요해요. 결제 계정을 만든 Google 계정으로 로그인했는지 확인해요. |
| 금액 단위가 원(KRW)이 아니에요 | 결제 계정의 통화로 표시돼요. 같은 금액(약 1달러)으로 맞춰요. |
| **릴리스 보관 설정**이 안 보여요 | 한 번이라도 배포가 끝나야 릴리스 기록 표가 생겨요. 02의 확인 방법을 먼저 마쳐요. |
| 화면이 안내서와 달라요 | 스크린샷을 보내 주세요. 안내서를 고쳐 드릴게요. |
