# 05. 안드로이드 APK 설치하기

안드로이드 태블릿이 있을 때 GitHub Actions가 만든 APK(설치 파일)를 내려받아 설치해요. APK는 **Run workflow** 버튼을 눌렀을 때만 만들어져요 — 코드가 올라갈 때마다 자동으로 만들지 않아요(GitHub Actions 무료 사용 시간을 아끼려고요).

- **소요 시간**: 약 15분 (APK 만들기 약 10분 포함)
- **끝나면 Claude에게 알려줄 것**: 내려받은 파일 이름(`noteapp-apk-…` 또는 `noteapp-debug-signed-…`), 설치가 됐는지, 실행하면 라이브러리 화면이 나오는지, 새 APK를 지우지 않고 덮어 설치할 수 있었는지

## 준비물

- 안드로이드 태블릿 (64비트 — 요즘 기기는 대부분 해당돼요)
- 태블릿 브라우저(Chrome 등)와 이 저장소를 볼 수 있는 GitHub 계정

## 따라 하기

### 1단계 — APK 만들기

1. 태블릿(또는 컴퓨터) 브라우저로 <https://github.com> 에 로그인하고 저장소를 열어요.
2. 위쪽 **Actions**를 누르고 왼쪽 목록에서 **Android APK**를 눌러요.
3. 실행 목록 오른쪽 위 **Run workflow**를 눌러요.
4. **Use workflow from**이 `claude/note-app-planning-bk29xb`인지 보고 아래 초록색 **Run workflow**를 눌러요.
5. 목록 맨 위에 새 실행이 생겨요. 녹색 체크가 될 때까지 약 10분 기다려요.

GitHub는 저장소의 기본 브랜치에 있는 워크플로만 버튼으로 실행하게 해 줘요. `main`이 아직 없는 지금은 개발 브랜치 `claude/note-app-planning-bk29xb`가 기본 브랜치라 버튼이 보여요. 이 APK의 **설정 → 앱 정보 → 빌드** 줄 끝에는 브랜치 이름 `claude/note-app-planning-bk29xb`가 보여요. `main`이 생기면 **Use workflow from**에서 `main`을 고르면 돼요.

### 내려받기

APK는 저장소의 **Releases**(릴리스)에 `.apk` 파일로 올라가요. 압축 파일이 아니라 태블릿에서 바로 설치할 수 있어요.

1. 녹색 체크가 된 실행을 누르면 **Summary**에 '다운로드:' 줄이 있어요. 그 주소를 열어요. 또는 저장소 첫 화면 오른쪽(휴대폰 화면에서는 아래쪽)의 **Releases**를 눌러 맨 위 `noteapp-…-<번호>`를 열어도 돼요.
2. **Assets**에서 `noteapp-apk-<번호>.apk`(또는 `noteapp-debug-signed-<번호>.apk`)를 눌러 내려받아요.

파일 이름이 서명을 알려 줘요.

| 이름 | 뜻 |
|---|---|
| `noteapp-apk-<번호>` | 고정 키 판이에요. 다음 고정 키 판을 덮어 설치할 수 있어요. |
| `noteapp-debug-signed-<번호>` | 고정 키를 등록하기 전의 **덮어 설치할 수 없는 시험판**이에요. 실행마다 키가 달라서 기존 앱 위에 덮어 설치하지 못할 수 있어요. **실제 노트가 든 기기에는 설치하지 마세요.** |

가장 최근 3개만 남고 그보다 오래된 릴리스는 새로 만들 때 지워져요. 없으면 1단계처럼 **Run workflow**로 새로 만들어요. (예전에는 실행 화면의 **Artifacts**에 zip으로 올렸지만, GitHub 저장 용량 한도에 걸려 바꿨어요.)

### 2단계 — 내려받은 파일 찾기

1. 브라우저의 다운로드 알림을 누르거나 **파일**(또는 Files by Google) 앱 → **다운로드**를 열어요.
2. `noteapp-…-<번호>.apk` 파일이 있어요.

### 3단계 — 설치

1. APK 파일을 눌러요.
2. '보안상의 이유로 이 출처의 알 수 없는 앱을 설치할 수 없습니다' 같은 창이 나오면 **설정** → **이 출처 허용**을 켜고 뒤로 돌아와요.
3. **설치** → **열기**를 눌러요.

### 4단계 — 처음 쓸 때 허가하기

- 처음 녹음할 때 **마이크**와 **알림** 허가를 물어요. 둘 다 허용해요. 알림은 화면을 꺼도 녹음이 이어지는 동안 보여요.
- 손글씨 인식은 언어 모델을 처음 한 번 내려받아요(언어마다 약 20 MB — 미확인). **Wi-Fi에 연결된 상태에서** 받아요.
- 확인할 항목은 [08. 실기기 체크리스트](08-device-checklist.md)의 A에 있어요.

## 새 버전으로 바꿀 때

고정 키 등록은 [07. 안드로이드 고정 서명 키 등록하기](07-android-signing.md)를 보세요(키는 Claude가 파일 두 개로 건네요 — Claude는 GitHub 설정을 직접 바꿀 수 없어요).

- **고정 키 판(`noteapp-apk-<번호>`)끼리는 덮어 설치해요.** 앱을 지우지 않고 새 APK를 설치하면 노트·이미지·녹음이 그대로 남아요.
- **처음 한 번은 기존 앱을 지우고 설치해요.** 1차 판과 고정 키 전의 시험판(`noteapp-debug-signed-<번호>`)은 실행마다 다른 키로 서명돼서 고정 키 판을 그 위에 덮어 설치하지 못할 수 있어요(1차 판은 노트를 저장하지도 못했어요). 앱을 지우면 태블릿에 저장된 노트도 지워져요. 그 뒤로는 덮어 설치해요.
- **'앱이 설치되지 않음'이 뜨면 앱을 지우지 말고 Claude에게 알려 주세요.** 지우면 기기의 노트가 사라져요. 대개 서명이 다른 APK를 받은 경우라서 Claude가 맞는 APK를 알려 드려요.
- 기기 자동 백업에 노트가 들어가지 않아요. 앱을 지우거나 기기를 바꾸면 노트가 돌아오지 않아요. 백업 내보내기를 해 두세요(**설정 → 앱 정보 → 백업 내보내기**).

## 확인 방법

- 앱을 열면 라이브러리 화면이 나와요.
- **설정 → 앱 정보 → 빌드** 줄의 `#` 뒤 번호가 내려받은 `noteapp-apk-<번호>.apk`의 번호와 같아요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| **Releases**에 APK가 없어요 | 최근 3개보다 오래됐거나 실행이 실패했어요. **Run workflow**로 새로 만들어요. 실패하면 Claude에게 알려 주세요. |
| 코드를 올렸는데 새 APK가 없어요 | APK는 자동으로 만들지 않아요. 1단계처럼 **Run workflow**를 눌러 주세요. |
| **Run workflow** 버튼이 없어요 | 왼쪽 목록에서 **Android APK**를 먼저 눌러야 보여요. 그래도 없으면 저장소 주인 계정으로 로그인했는지 확인하고 Claude에게 알려 주세요(GitHub는 기본 브랜치에 있는 워크플로만 버튼으로 실행해요). |
| **Branch** 필터에 개발 브랜치가 없어요 | 그 브랜치에서 아직 APK를 만든 적이 없어요. 1단계처럼 **Run workflow**를 눌러 주세요. |
| 파일을 눌러도 설치 화면이 안 나와요 | **Files by Google** 앱의 **다운로드**에서 `.apk` 파일을 눌러요. |
| '앱이 설치되지 않음' / '패키지가 기존 패키지와 충돌합니다' | **앱을 지우지 말고** Claude에게 알려 주세요. 내려받은 파일 이름도 함께요. 처음 고정 키 판으로 바꾸는 때라면 위 '새 버전으로 바꿀 때'의 '처음 한 번' 순서예요. |
| 손글씨 인식이 시작되지 않아요 | 언어 모델을 아직 받지 못했을 수 있어요. Wi-Fi에 연결하고 잠시 기다려요. |
| Play 프로텍트 경고가 떠요 | 직접 만든 앱이라 나오는 경고예요. **세부정보 더보기** → **무시하고 설치**(문구는 기기마다 달라요 — 미확인). |
| '이 기기와 호환되지 않음' | 32비트 기기일 수 있어요. 태블릿 모델 이름을 알려 주세요. |
| 화면이 안내서와 달라요 | 스크린샷을 보내 주세요. 안내서를 고쳐 드릴게요. |
